Mission guide

Three lanes, one tide, one verdict

The lab runs a 52-week race between three identical engineers who differ only in when their reps start. This page maps every lane, control, and readout to the claim it proves.

Honest limits. The model is deliberately simple — linear skill gain, a smooth exponential tide. Real careers are noisier, which makes the mechanism harder to see, not weaker.

Start here

What this demo proves

Skill and output compound per shipped iteration; the model's improvement is a flat multiplier applied to everyone equally. Press Run 52-week race: the ship-weekly lane finishes far ahead, the learn-only lane drifts, and the wait-perfect lane — identical cadence, delayed start — earns a CATCH-UP: NEVER stamp. Then raise Model gain / week: the tide lifts every lane and widens the absolute gap.

The lanes

Three engineers, three trajectories

Lane 01

Ship Weekly

Ships one rep every week from week 1. Each ship adds learnPerShip to skill; from the second ship on, real-user feedback adds feedbackBonus too.

Proves
reps, not elapsed time, are the compounding base.
Key detail
52 ships by T+52 — feedback bonus active from week 2.
Lane 02

Learn Only

Consumes every release note and eval, runs nothing. Skill drifts up by learnOnlyDrift (0.005) weekly, but no ship means no feedback and no multiplier base.

Proves
changelog fluency is not building skill.
Key detail
finishes with real skill but a fraction of the output.
Lane 03

Wait for Perfect

Holds the pad for the configurable wait window — rusting at rustPerIdleWeek per week — then ships on the identical weekly cadence.

Proves
the failure mode: a delayed start buys a gap that never closes.
Key detail
catchUpWeek returns null — stamped NEVER.

The controls

Mission parameters

Control 01

Wait window

Weeks the waiter idles before its first ship — the "once the tooling settles" delay, adjustable from 0 to 40.

Proves
waiting is a renewable decision; every extra idle week deepens the hole.
Key detail
idle weeks apply rust, so the waiter starts below its launch skill.
Control 02

Learn per ship

Skill gained per shipped rep — the strength of the practice effect.

Proves
even a small per-rep gain, compounded weekly, dominates any head start in reading.
Key detail
set it to 0 and the lanes collapse — reps are the engine.
Control 03

Model gain / week

The tide: (1 + gain) ** week, multiplying everyone's weekly output identically.

Proves
a rising tide does not rescue the waiter — it multiplies whatever base exists.
Key detail
the cyan dashed line on the chart; equal for all three lanes.
Control 04

Step mode

Step +1 week advances the race one frame at a time — the same stepWeek transition that drives the article's animated figure.

Proves
the divergence is invisible early: at T+04 the lanes look tied.
Key detail
every transition is pure and deterministic — same inputs, same race.

The readouts

Telemetry

Readout 01

MET clock

Mission-elapsed-time chip, T+WW, tracking the current week during step mode.

Proves
the clock runs whether you fly or hold the pad.
Key detail
the horizon is fixed at 52 — weeks idle are weeks spent.
Readout 02

Stall report

Evidence on the wait-perfect lane: idle weeks, ships during the wait window (always 0), and the output gap at launch and at T+52.

Proves
the gap widens after liftoff even on identical cadence.
Key detail
stallReport(sim) — same function the tests assert on.
Readout 03

Catch-up stamp

The first week the waiter's cumulative output reaches the leader's — or CATCH-UP: NEVER when catchUpWeek returns null.

Proves
inside a fixed horizon, a late start can be mathematically unclosable.
Key detail
under default parameters the verdict is always NEVER.

Run locally

Inspect the evidence

npm start        # serve the lab on :3000
npm test         # unit tests + end-to-end server suite
npm run race     # CLI: weekly table + stall report
npm run check    # both

Try node scripts/race.mjs --wait=24 to deepen the stall, or --gain=0.05 to watch the tide widen the gap.

Limits

What this demo does not claim

  • Skill gain is linear per rep; real learning curves bend both ways.
  • The tide is a smooth exponential; real model releases arrive in jumps.
  • Output is cumulative with no market noise, luck, or distribution effects.
  • Three stylized lanes stand in for real careers — the mechanism is the point, not the magnitudes.
  • A "ship" counts any rep; the model says nothing about which rep is worth shipping.
